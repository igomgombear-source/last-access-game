# v13.2 디자인 개편

기준 버전: v13.1.1 · 결과 버전: v13.2.1 · 작업일: 2026-11-06

## 화면의 기준

권해인의 휴대폰은 개인이 사용하는 기본 앱의 모습을 따르고, 승민의 조사 수첩은 종이·문서·주석으로 구분한다. 기존 남색 카드와 큰 선택 버튼을 모든 화면에 반복하던 방식을 줄였다. 새로운 사건·인물 사진·증거 이미지·음원을 추가하지 않았다.

## 실제 변경

- 홈: 달력과 기존 리허설 재생목록을 작은 위젯으로 구성했다. 기존 모든 앱과 음악 경로를 유지했다. 권해인과 승민의 배경은 구분했다.
- 메시지: 대화 상대·발신 방향·시각·원문 열기를 구분했다. 과거 대화에 가짜 실시간 접속 표시나 입력창을 넣지 않았다. 단서가 없는 문장도 보존했다.
- 앱: 체크·돋보기로 표현하던 목록 아이콘을 연락처·파일·통화 등 항목에 맞게 정리했다. 메모는 목록, 문서는 원본 용지, 사진은 썸네일 중심으로 표현한다.
- 수첩: 완료·잠김·자료 부족 조건을 유지하며 평면적인 기록 목록, 구분선, 종이색과 주석색을 사용한다.
- 도움말: 기존의 다음 행동 안내를 '승민의 메모'에서 펼쳐 확인한다. 도움말과 휴대폰·수첩 도구를 한 줄에 배치하고, 도움말은 그 위로 열린다. 힌트·저장·보관·수첩 기능을 유지한다.
- 평가표: 원래의 두 평가표와 모든 수치를 그대로 표시한다. 표시한 셀은 원형 주석으로 강조한다. 실제 작은 화면 검토에서 비교에 필요한 스크롤이 길어 제목·용지 여백을 축소했다. 기존 정답·오답 선택과 제출 판정은 기존 엔진을 사용한다.
- 최종 추리: 행적·인물·경위·근거를 네 항목으로 나누었다. 선택한 행적을 개별 해제할 수 있고, 선택한 인물·경위·근거와 현재 항목은 저장된다. 원문을 읽고 돌아와도 선택을 유지한다.
- 타이틀·도입·메뉴: 같은 서체·사진·종이와 잉크 계열의 색으로 정리했다. 새 게임·이어하기·설정·건너뛰기·무음 진행을 유지한다.

## 보존과 검사

기존 v13.1.1의 소스·스타일·에셋 36개를 해시로 보존한다. 실행 HTML과 버전 manifest를 갱신하고 `art-direction.js`, `art-direction.css`를 추가했다. 화면 함수 일부를 덮어쓰므로 실제 화면 구성이 구버전과 같다는 뜻은 아니다.

기존 핵심 사건·대사·원문 데이터·정답·단서 공개 조건·저장 키는 변경하지 않았다. 최종 추리의 현재 항목을 저장하는 `artFinalStep`만 추가한다. 새 화면은 기존 판정 함수를 호출한다.

정적 검사 122개, 기존 판정 11사례·추가 판정 28사례·최종 화면 범위 8사례·저장 필드 8개를 검사했다. 로컬 HTML이나 localhost에서 게임을 실행하지 않았다. 실제 HTTPS 결과와 화면 증거는 [검증 결과](v13.2-검증결과.md)에 기록한다.
