# v13.2.1 디자인 개편 검증 결과

검증일: 2026-11-06 · 사건과 정답의 스포일러가 있다.

실제 실행: https://igomgombear-source.github.io/last-access-game/

## 검증한 버전과 경로

v13.2.0을 HTTPS에 배포한 뒤, 기존 v13.1 완료 저장을 이어 열고 새 게임도 진행했다. 새 게임에서 A 필수 7개·선택 3개, B 필수 6개, 새 최종 추리와 TRUE END를 확인했다. BP5의 사진·직접 목격 두 정답을 검사하기 위해 중간 수동 저장을 복원했다. 전체 과정이 단 한 번의 중단 없는 실행이었다는 뜻은 아니다.

작은 화면 검토에서 평가표 비교의 스크롤이 길고 조사 화면의 제목이 중복해 크게 보이는 점을 발견했다. v13.2.1에서 용지·제목 여백을 축소하고 앱 제목 크기를 정리했다. 도움말과 게임 도구도 한 줄로 묶었다.

v13.2.1에서는 B6 완료·사건 미해결 상태의 수동 저장을 복원해 새 최종 추리 네 항목을 다시 선택하고 TRUE END에 도달했다. 별도의 새 게임에서 건너뛰기·무음 도입·암호 해제·평가표 열람·수정된 비교 화면의 정답 처리까지 다시 확인했다. v13.2.1에서 A/B 전체를 처음부터 다시 반복한 것으로 보고하지 않는다.

로컬 HTML과 localhost에서 게임을 실행하지 않았다. 아래 실제 플레이 결과와 정적·순수 함수 검사를 구분한다.

## 디자인 판단과 남은 범위

개인 폰, 원본 문서, 조사 수첩에 각각 맞는 표현을 적용하고 서체·색·구분선의 기준을 통일했다. 반복되는 남색 카드와 큰 선택 상자를 줄였다. 최종 추리는 네 항목 중 하나에 집중하고 선택한 자료를 원문과 왕복할 수 있다. 작은 화면에서는 모양뿐 아니라 비교에 필요한 정보가 함께 보이는지도 다시 확인했다.

상업용 게임의 디자인 경쟁력이 입증됐다는 판정은 하지 않는다. 새 인물 촬영·음성 연기·개인화 에셋을 제작한 버전도 아니다. 실제 iOS Safari·Android Chrome, 가상 키보드·노치·주소창·오디오 정책의 조합과 모든 분기·저장 시점을 전수 검사하지 않았다. 신규 이용자가 힌트 없이 역할과 다음 행동을 이해하고 단서의 의미를 설명하는지 관찰하는 검토도 남아 있다.
