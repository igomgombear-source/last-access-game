# 마지막 접속 · v13.2.1

[게임 실행](https://igomgombear-source.github.io/last-access-game/)

교사 이승민이 동료 권해인의 휴대폰에 남은 기록을 통해 사건을 조사하는 단편 추리 게임입니다.

## 이번 수정

- 휴대폰은 기본 앱의 목록과 대화로, 조사 수첩은 종이·문서·주석으로 표현합니다.
- 반복되는 남색 카드와 큰 선택 상자를 줄이고 타이틀·메뉴·도입의 서체와 색을 통일했습니다.
- 두 평가표의 수치를 직접 비교하고 선택한 숫자를 원형 주석으로 표시합니다.
- 최종 추리는 행적·인물·경위·근거를 한 항목씩 정리하며 원문 왕복과 저장을 유지합니다.
- 한 줄 게임 도구에서 필요할 때 '승민의 메모'를 펼칩니다. 기존 사건·앱·자료·정답·저장·엔딩은 유지합니다.

## 검토와 검증

디자인 개편판 v13.2.0을 실제 HTTPS에서 새 게임으로 진행해 A 필수 7개·선택 3개, B 필수 6개와 TRUE END를 확인했습니다. v13.2.1에서는 작은 화면 보강 후 평가표와 최종 추리·엔딩·저장 복원·건너뛰기·무음 진행을 다시 확인했습니다. 실제 iOS·Android 기기와 모든 분기는 검사하지 않았으며 상업성이나 일반 이용자의 재미가 입증됐다는 뜻은 아닙니다.

로컬 게임 실행 없이 검사: `node checks/check.mjs`
자동 검사는 파일·구문·해시 보존과 판정 함수만 확인하며 플레이 검증을 대신하지 않습니다. 이전 버전 파일 36개, manifest 39개, 기존 판정 11사례·추가 판정 28사례·최종 항목 값 8사례, 저장 필드 8개 검사를 통과했습니다.

Pages 배포: Actions → Validate and deploy game → Run workflow. `site/`만 배포됩니다. `docs/`의 QA 자료는 게임 진행에 포함되지 않습니다. 패키지를 옮길 때 숨김 `.github/`도 포함해야 합니다.

저장은 같은 브라우저와 사이트 주소에서 이어집니다. 기존 완료 저장은 새 추리를 강제로 다시 요구하지 않습니다. Netlify에서 GitHub Pages처럼 주소가 바뀌면 브라우저 저장은 자동 이전되지 않습니다.

장식용 음악실 배경은 내장 이미지 생성으로 제작했습니다. 사건의 증거 사진·영상으로 사용하지 않습니다. 리허설의 짧은 가이드는 이 프로젝트에서 합성한 독립 음원입니다.
