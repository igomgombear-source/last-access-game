- 상황 소개와 리허설 업무, 반환 약속 경과, 행방 확인, 알림을 통한 조사 시작.
- 개인 휴대폰 홈·잠금 화면·벡터 아이콘·앱 디자인 및 별도 조사 수첩.
- 읽을 때 원문 제공, A 추리 중 관련 자료 재열람.
- B의 전달 경로·시점·문서 연결과 마지막 행적 재구성.
- 기존 사건의 진상, A7+선택3, B6, 보관·저장·불러오기·엔딩 보존.

## 검토와 검증

수정 전 v13과 개선판 v13.1.0을 배포된 HTTPS 주소에서 실제 플레이해 TRUE END를 확인했습니다. v13.1.1은 엔딩 후 목표 문구·버전 표시의 후속 수정입니다. 주요 경로와 오답·재시도, 자동 복구·수동 저장·구버전 저장 복원, 세로·가로 뷰포트를 검사했습니다. 실제 iOS·Android 기기와 모든 분기는 검사하지 않았으며 상업성이나 일반 이용자의 재미가 입증됐다는 뜻은 아닙니다.

- [수정 전 출시 품질 검토보고서](docs/출시품질-검토보고서.md) — 스포일러 포함
- [수정 내역과 실제 검증 결과](docs/수정후-검증결과.md) — 화면·플레이 증거, 범위와 한계
- [신규 에셋 기록](docs/신규-에셋-기록.md)
- [배포 검증 데이터](verification.json)

로컬 게임 실행 없이 검사: `node checks/check.mjs`
자동 검사는 파일·구문·해시 보존과 판정 함수만 확인하며 플레이 검증을 대신하지 않습니다. 기준 파일 28개, manifest 37개, 기존 판정 11사례·추가 판정 28사례, 저장 필드 7개 검사를 통과했습니다.

Pages 배포: Actions → Validate and deploy game → Run workflow. `site/`만 배포됩니다. `docs/`의 QA 자료는 게임 진행에 포함되지 않습니다. 패키지를 옮길 때 숨김 `.github/`도 포함해야 합니다.

저장은 같은 브라우저와 사이트 주소에서 이어집니다. 기존 완료 저장은 새 추리를 강제로 다시 요구하지 않습니다. Netlify에서 GitHub Pages처럼 주소가 바뀌면 브라우저 저장은 자동 이전되지 않습니다.

장식용 음악실 배경은 내장 이미지 생성으로 제작했습니다. 사건의 증거 사진·영상으로 사용하지 않습니다. 리허설의 짧은 가이드는 이 프로젝트에서 합성한 독립 음원입니다.
