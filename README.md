Pages 배포: Actions → Validate and deploy game → Run workflow. `site/`만 배포됩니다. `docs/`의 QA 자료는 게임 진행에 포함되지 않습니다. 패키지를 옮길 때 숨김 `.github/`도 포함해야 합니다.

저장은 같은 브라우저와 사이트 주소에서 이어집니다. 기존 완료 저장은 새 추리를 강제로 다시 요구하지 않습니다. Netlify에서 GitHub Pages처럼 주소가 바뀌면 브라우저 저장은 자동 이전되지 않습니다.

장식용 음악실 배경은 내장 이미지 생성으로 제작했습니다. 사건의 증거 사진·영상으로 사용하지 않습니다. 리허설의 짧은 가이드는 이 프로젝트에서 합성한 독립 음원입니다.
